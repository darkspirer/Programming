# About C++ computer language 
C++ programming language was created starting in 1979 by Danish scientist Bjarne Stroustrup at Bell Laboratories. Initially, this language was called "C with Classes," because the author wanted to add object-oriented programming capabilities to the C language. In 1983, the language was officially named C++, and in 1985, its first commercial version was released to the public. In 1998, C++ was formally standardized as an international standard for the first time (C++98), followed by updated standards such as C++11, C++14, C++17, C++20, and C++23. Today, C++ remains one of the world's most widely used and reliable languages for creating operating systems, game engines, financial software, applications, and high-performance systems.

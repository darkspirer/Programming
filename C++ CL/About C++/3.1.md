# Pointers and arrays 
In programming (especially in C and C++), pointers and arrays are closely related. In practice, the name of an array acts as a pointer pointing to its first element.

When you declare an array, the array name holds the memory address of the first element.

Example: int arr[5] = {10, 20, 30, 40, 50};

Here, arr and &arr[0] point to the exact same memory address.

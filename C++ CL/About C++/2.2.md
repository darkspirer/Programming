# Looping constructs
### The while loop 
While loop (C++) — a control structure that repeatedly executes a block of code as long as a given condition remains true. The condition is checked before each iteration, so if it is false from the start, the loop body may never execute at all.

### do-while loop 

 A do-while loop is a loop that executes the code block at least once before checking the condition. Unlike a while loop, the loop body runs first, then the condition is evaluated — if true, it repeats; if false, it stops.

### for loop 

A for loop is used when the number of iterations is known in advance. It combines three parts in a single line: initialization, condition, and increment/decrement — making loop control compact and organized.

### Break and continue 
- break - exits the loop immediately and unconditionally ends the loop’s operation; the program begins to execute the nearest instruction after the loop's body;
- continue – behaves as the program suddenly reached the end of the body; the end of the loop's body is reached and the condition expression is tested immediately.

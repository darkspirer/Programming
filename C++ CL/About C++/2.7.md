### Not only vectors
A 2D array can be compared to a chessboard. In mathematics, we can imagine it as a square or a rectangle.

A 3D array is like a cube. You can imagine it as a stack of several 2D tables (layers) placed on top of each other. It has 3 directions: rows (i), columns (j) and depth (k). To find one element you need 3 indices: a[i][j][k].

# Input and output
- Sending data in the direction from human (user) to the computer program is called input.
- The stream of data transferred in the opposite direction, i.e. from the computer to the human, is called output.

### Output
In C++, we use cout to print the value of a variable and text messages to the screen (console).

Syntax:
- cout << "text";
- cout << value;

This is how we output values or text messages.

If we want, we can also chain them together:
- cout << "hello world " << value;

### Input
In C++, we use cin to receive a value from the user through the keyboard and store it in a variable.

Syntax:
- cin >> variable;

This is how the value entered by the user is stored in the variable named variable.

If we want, we can also receive several values one after another:
- cin >> a >> b;

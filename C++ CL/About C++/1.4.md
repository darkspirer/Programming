# Characters

In C++, there is also a character type. When we declare characters, we use the char keyword (data type)

### ASCII
ASCII (American Standard Code for Information Interchange) is a standard coding system used to represent characters in computers through numbers. It was developed in the United States in 1963 and is still widely used today. In the ASCII table, each character corresponds to an integer from 0 to 127. For example, the uppercase letter "A" corresponds to the number 65, while the lowercase letter "a" corresponds to 97. Digits also have their own codes — the character "0" represents the number 48. The ASCII table includes letters, digits, punctuation marks, and control characters (such as Enter or Tab). This system encodes data using only 7 bits (from 0 to 127, meaning 128 characters). In C++, a variable of type char actually stores an ASCII code (an integer), but it is displayed on the screen as a character. Because of this, in C++ it is possible to compare characters with numbers or perform arithmetic operations on them. For example, 'A' + 1 results in the character 'B', because their ASCII codes are consecutive. The extended version of ASCII (Extended ASCII) also includes additional characters ranging from 128 to 255.


#### ASCII is a widely used, universal standard that is employed in almost all modern computer systems. EBCDIC, on the other hand, is a less common coding system used only in IBM's older mainframe computers. Additionally, unlike ASCII, the letters in EBCDIC are not numbered consecutively — this can cause certain inconveniences in programming.

- \n – denotes a transition to a new line and is sometimes called an LF (Line Feed), as printers react to this character by pulling out the paper by one line of text.

- \r – denotes the return to the beginning of the line and is sometimes called a CR (Carriage Return – “carriage” was the synonym of a “print head” in the typewriter era); printers respond to this character as if they are told to re-start printing from the left margin of the already printed line.

- \a – (as in alarm) - is a relic of the past when teletypes were often used to communicate with computers (do you know what a teletype is, are you old enough to remember them?); sending this character to a teletype turns on its ringer; hence, the character is officially called BEL (as in bell); interestingly, if you try to send the character to the screen, you’ll hear a sound – it won't be a real ringing but rather a short beep. The power of tradition works even in the IT world.
- \0 (note: the character after the backslash is a zero, not the letter O): called nul (from the Latin word nullus – none) is a character that does not represent any character; despite first impressions, it could be very useful, as we’ll show you in the lessons to come.

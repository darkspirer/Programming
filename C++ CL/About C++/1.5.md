# Making Simple Decisions: Intro to Flow Control in C++
### Remember

In C++, we use the cout keyword to output words or text to the screen, using the syntax cout << "word or text";. 

This can also be used to prompt the user for input.

To read the value entered by the user, we use the cin keyword with the syntax cin >> x; (where x is a variable). 

Additionally, almost every statement in C++ must end with a semicolon (;), otherwise the code will fail to compile.

Computers always answer us with a yes or a no; they never give an 'I don't know' answer
-
### Operators 
- The == operator represents equality
- != is used to express 'not equal'
- The > symbol is used for 'greater than', and if it is 'greater than or equal to', we use >=
- The < symbol is used for 'less than', and if it is 'less than or equal to', we use <=

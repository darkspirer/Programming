# Operators
##  Floating-point numbers
Float numbers are a data type used to represent fractional (decimal point) numbers.
##### Note
Numbers that are powers of 10 are written using E notation (scientific
notation for computers/calculators).
- Format: a E n means a × 10ⁿ

## Operators 
- +,-,*,/.

##### Numbers cannot be divided by zero.
- % is the operator that produces the remainder (modulo operator).
- The "++" is called the increment operator.
- The "--" is called the decrement operator.

 In C++, the ++ (increment) and -- (decrement) operators behave differently depending on whether they come before or after the variable.

- Prefix (++x or --x): The value is changed first, and then the updated value is used.

 Example: if x = 5, then ++x makes x = 6, and 6 is the value used.

- Postfix (x++ or x--): The current value is used first, and only after that does the variable change.

Example: if x = 5, then x++ uses 5 as the value, and only afterward does x become 6.

## Shortcut operators 
- i = i * 2  ->  i *= 2
- sheep_counter = sheep_counter + 10  -> sheep_counter += 10

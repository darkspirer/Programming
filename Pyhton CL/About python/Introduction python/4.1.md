## About function
In Python, print(), len(), and input() are actually built-in functions. They are already created to perform specific tasks. Now, we are going to learn how to use these functions.

## Where do the functions come from?
- from Python itself - numerous functions(like print())are an integral part of Python and are always available without any additonal effort on behalf of the programmer; we call these functions built-in functions;
- directly from your code - you can write your own functions,place them inseide yor code and use them freely;

Functions are useful because we only need to change the code once, and the changes will affect every place where the function is used.

##  How functions work
- when you invoke a function, Python remembers the place where it happened and jumps into the invoked function;
- the body of the function is then executed;
- reaching the end of the function forces Python to return to the place directly after the point of invocation.
- Remember: A function must be defined before it can be called. If you call a function before defining it, Python will raise an error.

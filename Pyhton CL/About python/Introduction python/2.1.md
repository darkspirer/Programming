### The first program is "Hello world"

- When we write something in input, we use the "print()" function to display it as output.
- To display words as output, they must always be written inside double quotes.

print("Hello world")

### The second function is  /n. 

This is newline function. That is, it prints the line we write on a new line.

print("Hello /nworld")

output;

Hello 

world

### When we use a comma , in print, it leaves a space in the output.

print("hello","world")

output:

hello  world 

### end=""  
It allows you to insert a space between words in two print functions, write them together without a space, or put any letter or symbol in between.

print("hello",end="--")
print("world")

ouput:

hello -- world

### sep=""
This is somewhat similar to end="", but the difference is that it allows you to insert a space, stick words together, or put letters and symbols between words within a single print.

print("hello","world",sep="--")

output:

hello--world

## BMI function 
BMI (Body Mass Index) is a measurement used to determine whether a person's body weight is within a healthy range for their height.

## Recursion 
Recursion is a programming technique in which a function calls itself.

Simply put, a function solves a problem by breaking it down into smaller parts and then calling itself to solve those smaller parts. This process continues until a base case (stopping condition) is reached.

# Making decisions in Python
## Comparison: equality operators "=="
- = is an assignment operator, e.g., a = b assigns a with the value of b;
- == is the question are these values equal? so a == b compares a and b.
- If we want to say “not equal,” we use the != symbol.
## Operators that compare greater and smaller values.
- To compare whether a value is bigger or smaller, we use the < and > symbols.
- If we want to compare whether a value is equal to or bigger/smaller than another value, we use the <= and >= operators.
## Operators 
- ** - Exponentiation operator.
- // - Floor division operator.
- % - Modulo operator.
## Conditions and conditional execution
When we want a program to execute or not execute something based on a condition, we use a conditional operator.

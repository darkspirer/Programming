# Operations on lists 
list1[] = list2[:]

- When [:] is used, it creates a copy of the original list. This copy is stored separately, so if the original list changes later, the copied list does not change. However, if [:] is not used, the second variable refers to the same list as the original one. Therefore, if the original list changes, the second list changes as well.

- Using list_name[start:end], we can create a copy of a specific range of elements from a list.

## Slices 
When we use slicing, it starts from the specified starting index and ends at the element just before the specified ending index.

We can use negative indexes in slicing. However, when a negative index is used as the starting index, there must be a valid range between the start and end indexes. Otherwise, no elements will be returned.

## del function 
We can also use the del statement to delete multiple elements from a list by specifying a slice.

Example:

del list_name[1:3]

This deletes the elements from index 1 up to (but not including) index 3.

## The in and not in operators 
The in and not in operators are used to check whether an element exists in a list. The result is a Boolean value (True or False).

# Comments
Python has two types of comments.

- This is a single-line comment.

By using #, you can create a single-line comment.

- This is a multi-line comment.

By using """ """ or ''' ''', you can create a multi-line comment.

Python shortcut for comments:

- Ctrl + / → comment/uncomment lines on Windows/Linux
- Cmd + / → comment/uncomment lines on Mac

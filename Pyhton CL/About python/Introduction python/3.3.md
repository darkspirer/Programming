# Logic and bit operations in python 
## The and operator 
The and operator in Python is used to combine two or more conditions. It returns True only when all of the conditions are True.
## The or operator 
The or operator in Python is used to combine two or more conditions. It returns True if at least one of the conditions is True.
## The not operator(!)

The not operator is used to reverse the result of any Boolean expression.

- & (ampersand) ‒ bitwise conjunction;
- | (bar) ‒ bitwise disjunction;
- ~ (tilde) ‒ bitwise negation;
- ^ (caret) ‒ bitwise exclusive or (xor).

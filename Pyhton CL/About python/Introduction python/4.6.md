# Tuples and dictionaries
## Sequen\ce and mutability types
- List = Mutable Sequence 
- Tuple = Immutable Sequence
## Tuple
A tuple is an immutable sequence data type in Python that is used to store multiple values.

Simply put:

A tuple is a data type that stores elements in a sequence, but once it is created, its elements cannot be modified.

- A tuple is created using parentheses ().

- The elements inside a tuple are separated by commas.

- To create an empty tuple, simply use empty parentheses without adding any elements inside.
- Not all of the operators and methods available for lists work with tuples because tuples are immutable.
## Dictionaries
- A dictionary is created using curly braces {}.
- In a dictionary, each key has its own value. We use a colon (:) to assign a value to each key.

To access a value in a tuple or a dictionary, we usually use square brackets [].

In a tuple, we use an index inside the square brackets to access an element.
-


In a dictionary, we use a key inside the square brackets to access a value.
-


- Tuple → use an index inside [].
- Dictionary → use a key inside [].

## Dictionary methods and functions
### The keys() method
The keys() function returns only the keys to us.
- .values() - Returns only the values.

- .items() - Returns (key, value) pairs.
- If we want to add a new key to a dictionary, we simply write the dictionary name along with its key and value. That's it
- The update() method adds data to a dictionary from another dictionary (or from key-value pairs), or updates the value of existing keys
- Keys are removed using del().
#### popitem() method 
- Before Python 3.7 — dictionaries were unordered, so popitem() would remove a random element.
- Since Python 3.7 — dictionaries preserve order, so popitem() no longer removes a random element, but specifically removes the last inserted element.

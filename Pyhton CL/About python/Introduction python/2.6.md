# The input() function
The input() function is able to read data entered by the user and to return the same data to the running program.

We can use the input() function to enter data in the output section.

The required data can be entered using input(), and we can also present the input as a question in the output.

But there are also cases where it gives an error.

For example.

In the output section, we cannot directly enter an integer (int) value.

In this case, we need to add the int conversion before the input() function, like this: int(input()).

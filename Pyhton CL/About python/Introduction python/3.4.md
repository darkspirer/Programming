# Lists 
In Python, a list allows us to store multiple values in a single variable. This saves time because we don't need to create a separate variable for each value.

- A list is enclosed in square brackets [ ].

To create a list, we give it a name, use the assignment operator (=), and write the values inside square brackets ([]). We can include as many values as we want.
- 
- The first element of a list is always counted from zero. In other words, its first index is 0.
## Indexing lists 
To assign a new value to an element in a list, we use its index.
-
fruits = ["apple", "banana", "orange"]

[ fruits[1] = "grape" ]( lists indexing )

print(fruits)

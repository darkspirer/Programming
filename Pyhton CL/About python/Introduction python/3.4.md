# Lists 
In Python, a list allows us to store multiple values in a single variable. This saves time because we don't need to create a separate variable for each value.

- A list is enclosed in square brackets [ ].

To create a list, we give it a name, use the assignment operator (=), and write the values inside square brackets ([]). We can include as many values as we want.
- 
- The first element of a list is always counted from zero. In other words, its first index is 0.
## Indexing lists 
To assign a new value to an element in a list, we use its index.

Example


fruits = ["apple", "banana", "orange"]

[fruits[1] = "grape"](lists_indexing)

print(fruits)

- To swap the values at two indexes, assign them to each other in a single statement.
- - my_list[1], my_list[5] = my_list[5], my_list[1]

If we want one element in a list to take the value of another element, we assign it using the element's index.

numbers = [10, 20, 30, 40, 50]

numbers[1] = numbers[4]

## The len() function 
We use the len() function to find the number of elements in a list.
- len(lists_name)

## Removing elements from a lists
To delete an element from a list, we use the del statement followed by the index of the element.

del list[index_number]

This removes the element at the specified index from the list.
## Negative indices 
A negative index is an index that starts with a minus (-) sign. It counts the elements from the end of the list to the beginning.

## Function and methods
A method does all these things, but is also able to change the state of a selected entity.

A method is owned by the data it works for, while a function is owned by the whole code.
- result = function(arg)
- result = data.method(arg)

## Adding elements
There are two ways to add elements to a list:

- append(value) – This method always adds an element to the end of the list.
- insert(index, value) – This method inserts an element at any specified position in the list.
